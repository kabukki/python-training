# Python Training

A collection of exercises and experiments to get comfortable with Python, coming from a TypeScript background. Each exercise focuses on solving a small problem while exploring Python idioms and standard library features.

## Exercises

| File | Topics covered |
|------|---------------|
| `callstack.py` | Sampling profiler trace reconstruction. `dataclass`, `enum`, `zip`, `zip_longest`, `enumerate`, tuple unpacking, slicing, generator expressions, `next()` |
